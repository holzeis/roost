Roost – Use of Encryption

Export compliance documentation for the iOS app · 3 October 2026

1. Product

App nameRoost
Bundle IDme.holzeis.roost.roost (with extensions …ShareExtension and …NotificationServiceExtension)
Version1.0.0
DeveloperRichard Holzeis
DescriptionA private family chat app: text messages, photos and videos, video calls and live location sharing. It connects only to a chat server that the family runs on its own hardware, reached over the family's private network. The app is free.
Source codePublicly available at https://github.com/holzeis/roost

2. Summary

  • The app uses only standard, published encryption algorithms (IETF RFCs). It contains no proprietary or non-standard cryptography.
  • Encryption is used only to protect the user's own communications (message previews in notifications, call media) and to connect to services. It is not user-configurable, and the app offers no general-purpose encryption to users or other apps.
  • Some of this encryption is performed by Apple's operating system (CryptoKit, Keychain, URLSession/TLS). Some is performed by libraries bundled in the app (WebRTC's BoringSSL, the Flutter engine's BoringSSL, and the Dart cryptography package).
  • The app is intended for private use within the author's family only. It works solely inside the author's own Tailscale network, where the family's chat server runs, and is of no use to anyone outside that network. It is listed on the App Store, free of charge, only as the means of installing it on the family's devices.
  • The app is not made available in France.

Same preview encryption as the first row, for the app's Android version. The code is compiled into the iOS app but not executed on iOS X25519, HKDF-SHA-256, ChaCha20-Poly1305 (256-bit) RFC 7748, RFC 5869, RFC 8439 Dart cryptography package (open source)
HTTPS connections made by bundled SDKs: Firebase Cloud Messaging and Google Maps TLS 1.2 / 1.3 RFC 5246, RFC 8446 Apple URLSession (operating system)

The app's connection to the family's own chat server is HTTP and WebSocket inside the family's private network. That network's encryption (WireGuard, provided by the separate Tailscale app) is not part of Roost.

4. Not used

  • No proprietary, custom or non-standard algorithms.
  • No encryption that users can configure, select or apply to their own data or to other apps.
  • No encryption of files or storage beyond iOS's own data protection.
  • No network infrastructure, VPN or cryptographic functionality offered to other software.

5. Classification and distribution

  • Self-classified by the developer as mass-market encryption software (ECCN 5D992.c) under the U.S. Export Administration Regulations, using only standard cryptography.
  • Distributed only through the App Store, free of charge. Although the listing is publicly available, the app can only be used by members of the author's family on the author's private Tailscale network. Not made available in France.
